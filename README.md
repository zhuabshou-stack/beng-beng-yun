# 蹦蹦云

版本：v2.8.0
引擎：Cocos Creator 3.8.8
目标平台：抖音小游戏，同时保留浏览器预览
设计分辨率：1080×1920 竖屏

## 项目简介

《蹦蹦云》是一款梦幻治愈风格的 2D 竖屏休闲跳跃小游戏。玩家自动弹跳，通过手机左右半屏或电脑键盘控制水平移动，在云海中连续向上并收集金币与星星。

正式流程为 `assets/Boot.scene` → `assets/Home.scene` → `assets/Game.scene` → `assets/Home.scene`。`Main.scene` 保留不改，`HomeShell.scene` 保留但不参与正式构建。

## v2.8.0 主要变化

- 普通跳跃拥有更长的腾空观察时间；水平输入更快，松手后约 0.2 秒收束；镜头使用指数平滑与最大追赶速度。
- 普通落云、精准落点、弹簧云、Combo、金币和星星均有分级反馈；Combo 8/12 会进入有明确开始、持续和结束的冲刺状态。
- 落云压缩回弹、拖尾、粒子和浮字均使用固定对象池，不随游玩时间持续创建节点。
- 主页、HUD、暂停和结算重新整理；标准 UI 与大字模式继续持久化。
- 完成本地排行榜前十、累计统计、音效/音乐开关、重新查看教学、首次分步教学、里程碑与基础关卡完成反馈。
- 新增统一 `AudioManager` 可替换接口；本版本未下载或捆绑来源不明的音频素材。

## 操作

- 手机左半屏 / 右半屏：向左 / 向右移动。
- A、D 或左右方向键：水平移动。
- Esc：暂停或继续。
- 死亡结算后 R：重新开始。

## 核心规则

- 四种云概率保持不变：普通 75%、弹簧 5%、脆弱 10%、移动 10%，最多连续两朵特殊云。
- 云碰撞宽高、玩家碰撞半径、云间距和基础收集逻辑保持不变。
- 弹簧云速度倍率为 1.62；脆弱云踩中约 0.18 秒后破碎；移动云按 deltaTime 往返。
- 2.8 秒内踩到不同云增加 Combo；重复同云只给基础落地分，不延长 Combo。
- 精准落在云中心小范围内额外 +1 分；星星 +10 分；金币更新局内、总金币和本地存储。

## 运行与验证

1. 使用 Cocos Creator 3.8.8 打开本目录。
2. 以 `assets/Boot.scene` 为启动场景。
3. 浏览器预览或构建抖音小游戏；抖音开发者工具导入 `build/bytedance-mini-game`。

Creator 3.8.8 内置 TypeScript 编译器 `--noEmit --skipLibCheck` 已通过。720×1280 竖屏浏览器构建已完成页面交互与连续 10 分钟自动游玩回归：运行时异常 0，DOM 节点 26→26，Canvas 1→1，JS 堆未持续增长。

## 已知限制

- 皮肤、技能、正式抖音排行榜、正式分享、广告、云存档、支付、羽毛和商业化不在 v2.8.0 范围。
- 音频架构和开关已完成，但没有正式音频素材，当前不会伪造或下载来源不明素材。
- 浏览器自动操作不能替代用户对跳跃、镜头和弹簧手感的主观试玩，也不能替代最终真实手机验证。
- 抖音开发者工具 V4.5.4 已成功打开最终构建目录且编译日志无项目错误，但本机模拟器因远程资源 `net::ERR_SSL_BAD_RECORD_MAC_ALERT` 停在初始化；本次未把平台画面标记为通过。
