# 蹦蹦云

版本：v2.7.0
引擎：Cocos Creator 3.8.8
目标平台：抖音小游戏，同时保留浏览器预览
设计分辨率：1080×1920 竖屏

## 项目简介

《蹦蹦云》是一款梦幻治愈风格的 2D 竖屏休闲跳跃小游戏。玩家自动弹跳，通过手机左右半屏或电脑键盘控制水平移动，在云海中连续向上并收集金币与星星。

正式流程为 `assets/Boot.scene` → `assets/Home.scene` → `assets/Game.scene`。三个场景均由 Cocos Creator 3.8.8 正式创建和保存；原 `assets/Main.scene` 保留不改。节点由场景 Bootstrap 自动搭建，无需手工补复杂层级。

## v2.7.0 调整

- 新增独立 Boot、Home、Game 场景；主页不再覆盖在运行中的游戏世界上。
- Boot 提供约 1.5 秒原创云雾、星光、Logo 和轻量加载动画，并预加载 Home。
- Home 使用紧凑层级：开始按钮突出，其余功能为两行小入口；最高分、总金币和设置已接通，未完成功能明确显示“开发中”。
- 标准 UI 缩放为 0.82；大字模式只将 UI 放大到标准的 1.18 倍，并保存到 `cloudBounceUiMode`。
- 玩家视觉额外缩小 12%，云视觉额外缩小 12%，相机可视高度增加 20%；碰撞与所有物理参数保持不变。
- Home 与游戏 HUD 均读取抖音安全区；浏览器使用保守回退边距。
- HTML 功能审计见 `文档资料/HTML功能迁移矩阵.md`。

本版本不包含 combo 8/12 自动冲刺、完整技能、正式排行榜、广告、云存档或商业化系统。

## 操作

- 手机左半屏：向左移动。
- 手机右半屏：向右移动。
- A / 左方向键：向左移动。
- D / 右方向键：向右移动。
- Esc：暂停或继续。
- 死亡结算后 R：重新开始。

## 核心规则

- 四种云概率：普通 75%、弹簧 5%、脆弱 10%、移动 10%，最多连续两朵特殊云。
- 弹簧云提供 1.75 倍速度；脆弱云踩中约 0.18 秒后破碎；移动云按 deltaTime 往返。
- 2.8 秒内踩到不同云增加 Combo；重复同云只给基础落地分，不延长 Combo。
- 星星增加 10 分；金币更新局内、总金币和本地存储。

## 资源替换

当前缺少正式高清图片时使用 Cocos Graphics 占位。Canvas 的 `MinimalGameBootstrap` 保留玩家、四类云、金币、星星、天空、三层山峦、环境云、Logo 与 HUD 图标的 SpriteFrame 接口，可直接替换正式资源。

## 运行与验证

1. 使用 Cocos Creator 3.8.8 打开项目目录。
2. 打开 `assets/Boot.scene`。
3. 确认顶部预览场景为 Boot，点击预览按钮。

Creator 3.8.8 内置 TypeScript 编译器执行 `--noEmit --skipLibCheck` 已通过。393×852 竖屏预览已验证 Boot→Home→Game、标准/大字模式持久化、安全区、键盘/触摸、四种云、金币、星星、Combo、高度、HUD、死亡、R 重开和返回主页；干净会话控制台无 error/warning。抖音开发者工具与真实设备仍需在上架前验证。
