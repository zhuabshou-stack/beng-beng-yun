# 蹦蹦云

版本：v2.9.2（HTML 高一致度迁移试玩版）
引擎：Cocos Creator 3.8.8
设计分辨率：1080×1920，Portrait 竖屏

## 版本定位

本分支以 `D:\cesi2\游戏本体\index.html` 和拆分后的 HTML/CSS/JS 为唯一设计、规则和参数标准，把旧版《蹦蹦云》迁移到现有 Cocos 框架。它是“旧版高清 Cocos 复刻”，不是 v2.8.0 UI 的继续改版。

保留的底层框架：`Boot → Home → Game → Home`、`SceneNavigator`、`StorageService`、`DouyinBridge`、`AudioManager`、对象池和 Cocos/抖音构建结构。`Main.scene`、`HomeShell.scene` 保留但不参与正式构建。

## 已迁移内容

- 旧版深色星空主页、顶部金币/设置、Logo、开始按钮、六个功能卡片与底部操作信息。
- 主页与游戏内的皮肤、技能、排行榜、统计、设置页面；暂停、结算和关卡完成流程。
- 普通跳跃、水平加速/阻尼、环绕边界、四种云、碰撞、镜头、Combo、分数、高度、关卡目标。
- 金币、星星、羽毛，六套皮肤，六种技能及 1～6 键测试入口。
- 旧版落云/弹簧/Combo/收集浮字、粒子、拖尾、震屏和里程碑反馈；粒子、拖尾、浮字使用固定对象池。
- 本地最高分、总金币、前十排行、皮肤/技能/设置持久化；兼容旧版存储键。
- 首次游戏操作教学与抖音生命周期、安全区、分享入口隔离。

## 旧 HTML → Cocos 参数对照

旧版按 60 FPS 的“像素/帧”计算；Cocos 世界统一放大 2 倍并换算为“单位/秒”。

| 项目 | 旧 HTML | Cocos v2.9.2 | 换算/规则 |
|---|---:|---:|---|
| 重力 | 0.30 px/帧² | 2160 单位/秒² | `0.30 × 60² × 2` |
| 普通起跳速度 | -14 px/帧 | 1680 单位/秒 | 方向改为 Cocos 向上为正 |
| 最大水平速度 | 6 px/帧 | 720 单位/秒 | `6 × 60 × 2` |
| 水平加速度 | 0.30 px/帧² | 2160 单位/秒² | `0.30 × 60² × 2` |
| 松手阻尼 | 0.92/帧 | `0.92^(dt×60)` | 保留逐帧衰减 |
| 玩家半径 | 18 px | 36 单位 | ×2 |
| 云尺寸 | 70×20 px | 140×40 单位 | ×2 |
| 云间距 | 50～70 px | 100～140 单位 | ×2 |
| 弹簧倍率 | 2.0 | 2.0 | 不改规则 |
| 镜头阈值 | 屏高 40% | 屏高 40% | 同一阈值 |
| 镜头追随 | 差值 ×0.04/帧 | 跟随率 2.45/秒 | 60 FPS 指数等效 |
| 云概率 | 75/5/10/10 | 75/5/10/10 | 普通/弹簧/脆弱/移动 |
| 星星/金币/羽毛 | 25%/35%/8% | 25%/35%/8% | 独立抽取 |
| Combo | 每次成功落云 +1 | 同规则 | 下落错过云时清零；每 5 连击奖励 `floor(combo/5)` |

全部换算参数集中在 `assets/scripts/core/GameConfig.ts`。

## 运行与构建

1. 用 Cocos Creator 3.8.8 打开本目录。
2. 浏览器构建目录：`build/web-mobile-html-parity`。
3. 抖音小游戏构建目录：`build/bytedance-mini-game`。
4. 抖音构建只包含 `Boot.scene`、`Home.scene`、`Game.scene`，Boot 为初始场景，方向为 Portrait。

`build/`、`library/`、`temp/`、`local/`、`profiles/` 都是本机生成或私有状态，不提交 Git。抖音开发者工具应导入完整目录：

`D:\cesi2\蹦蹦云-Cocos工程\cese\build\bytedance-mini-game`
