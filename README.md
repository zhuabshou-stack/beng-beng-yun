# 蹦蹦云

版本：v2.9.4（HTML 高一致度复刻交互修正版）
引擎：Cocos Creator 3.8.8
设计分辨率：1080×1920，Portrait 竖屏

## 版本定位

`agent/html-parity` 以 `D:\cesi2\游戏本体` 内旧 HTML/CSS/JS 为页面、规则、参数和节奏的唯一参考，继续复用 Cocos 的 `Boot → Home → Game → Home`、`SceneNavigator`、`StorageService`、`DouyinBridge`、`AudioManager`、对象池及构建框架。它是旧版高清 Cocos 复刻，不延续 v2.8.0 的重新设计方向。

v2.9.4 在 v2.9.3 基础上集中修复主页/游戏设置的触摸穿透、技能不可用但无原因提示、开始游戏重复触发和僵硬白屏，并按本轮明确要求加入有上限的连续落云节奏增强。

## 已迁移内容

- 启动、主页、游戏、暂停、结算、关卡完成、皮肤、技能、排行、统计、设置和首次教学。
- 普通跳跃、水平控制、四种云、碰撞、镜头、Combo、分数、高度及关卡目标。
- 金币、星星、羽毛、六套皮肤及护盾、磁铁、时间减速、幽灵、二段跳、时光倒流六种技能。
- 落云、弹簧、Combo、收集、里程碑的粒子、拖尾、浮字和震屏；固定对象池避免运行期持续建节点。
- 最高分、金币、本地前十、皮肤、技能、设置持久化及旧存档键兼容。
- 分享入口通过 `DouyinBridge` 隔离；代码不直接使用 `window`、`document` 或 `navigator`。

## v2.9.4 关键修复

- 主页设置和游戏设置均使用全屏 `BlockInputEvents` 与事件传播阻断；关闭操作保留阻断到当前触摸结束，避免同一次触摸命中统计、暂停、主页或技能按钮。
- 主页音效、音乐和深色模式直接刷新当前设置行，不销毁重建面板；深色模式只切换主题，不会关闭设置或打开统计。
- 开始按钮点击后立即禁用；`preloadScene(Game)` 与 0.78 秒主页缩小淡出、两侧云雾掠过同步执行，二者都完成后才切场景；游戏世界在 0.38 秒内淡入，不再长时间白屏。
- 游戏设置打开即暂停并阻断下层输入；关闭只执行“关闭设置 → 恢复游戏”，不回到暂停面板。
- 六种技能保留旧 HTML 的价格、次数、持续时间和冷却；手机与 1～6 键共用真实逻辑，不可用时显示购买、次数、冷却、暂停或历史不足原因。
- 连续落到不同云时按 Combo 增强节奏，倍率每级 +0.035、最高 1.28；重力同步按倍率平方推进以缩短节奏而不改变普通跳高度。中断、护盾触发、死亡或重开恢复 1.0。
- Combo 同步增强镜头追赶、拖尾密度、起跳拉伸和落云粒子，均设上限；弹簧仍严格保持旧版 2 倍倍率。

## 旧 HTML → Cocos 参数对照

旧版按 60 FPS 像素帧计算，Cocos 世界按 2 倍换算为秒单位。

| 项目 | 旧 HTML | Cocos v2.9.4 | 规则 |
|---|---:|---:|---|
| 重力 | 0.30 px/帧² | 2160 单位/秒² | `0.30 × 60² × 2` |
| 普通起跳速度 | -14 px/帧 | +1680 单位/秒 | Cocos 向上为正 |
| 最大水平速度 | 6 px/帧 | 720 单位/秒 | `6 × 60 × 2` |
| 水平加速度 | 0.30 px/帧² | 2160 单位/秒² | `0.30 × 60² × 2` |
| 松手阻尼 | 0.92/帧 | `0.92^(dt×60)` | 保留逐帧衰减 |
| 玩家碰撞半径 | 18 px | 36 单位 | ×2；未修改碰撞体 |
| 玩家视觉半宽 | 约 30 px | 60 单位 | 用于完整可见边界 |
| 云尺寸 | 70×20 px | 140×40 单位 | ×2 |
| 云间距 | 50～70 px | 100～140 单位 | ×2 |
| 弹簧倍率 | 2.0 | 2.0 | 规则不变 |
| 镜头阈值 | 屏高 40% | 屏高 40% | 同一阈值 |
| 镜头追随 | 差值×0.04/帧 | 2.45/秒 | 60 FPS 指数等效 |
| 云概率 | 75/5/10/10 | 75/5/10/10 | 普通/弹簧/脆弱/移动 |
| 星星/金币/羽毛 | 25%/35%/8% | 25%/35%/8% | 独立抽取 |
| Combo | 落云 +1，错过清零 | 同规则 | 每 3 提示、每 5 奖励 |
| 连续落云节奏 | 固定 1.0 | 1.0～1.28 | 本轮用户明确要求；每级 +0.035，有上限 |
| 低帧物理 | 原版逐帧完整推进 | 0.1 秒上限、1/60 子步 | 修复此前 1/30 截断 |

参数统一位于 `assets/scripts/core/GameConfig.ts`。

## 运行与构建

1. 使用 Cocos Creator 3.8.8 打开本目录。
2. 浏览器发布目录：`build/web-mobile-html-parity`。
3. 抖音小游戏发布目录：`build/bytedance-mini-game`。
4. 正式构建只包含 `Boot.scene`、`Home.scene`、`Game.scene`，Boot 为初始场景；`Main.scene` 与 `HomeShell.scene` 不参与构建。

抖音开发者工具应导入完整目录：

`D:\cesi2\蹦蹦云-Cocos工程\cese\build\bytedance-mini-game`

`build/`、`library/`、`temp/`、`local/`、`profiles/` 均为本机生成或私有状态，不提交 Git。
