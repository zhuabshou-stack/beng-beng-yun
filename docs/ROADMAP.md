# 《蹦蹦云》开发路线

更新时间：2026-07-19
当前完成版本：v2.9.3 HTML 高一致度复刻修正版

## v2.9.3 已完成

- 保持 `agent/html-parity` 独立，未改 master 与 `agent/v2.8.0`。
- 修复云朵生成和移动越界，完整计算云半宽、边距和移动振幅。
- 删除玩家左右循环穿越，按碰撞与视觉尺寸限制屏幕边界。
- 通过 playerY、velocityY、cameraY 轨迹定位并修复低帧物理截断与相机时基不一致。
- 全屏 Camera/Canvas/背景/面板按实际竖屏尺寸刷新；安全区不缩小游戏世界。
- 修复主页设置后的深色主题覆盖；未完成主题入口不保留错误状态。
- 按旧 HTML 重整启动、主页、开场、HUD、暂停、主页按钮和技能入口。
- 保留已完成的完整页面、六套皮肤、六种技能、三类收集物、四种云、反馈和本地数据闭环。
- 完成 TypeScript、Creator 构建、浏览器流程、边界、下降轨迹和节点/堆稳定性检查。
- 生成加载、主页、开场、游戏、暂停和技能页截图，以及可重构建的浏览器/抖音本地发布包。

## 当前停止线

较完整可试玩版完成后停止。自动化只证明编译、构建、流程、边界和稳定性，不证明“好玩”。全部视觉与手感结论统一为：**等待用户试玩确认。**

## 等待用户反馈

- 跳跃高度、腾空时间和下降节奏是否符合旧 HTML。
- 水平响应、松手惯性、边界减速和取消穿越后的操作体验。
- 镜头阈值与跟随节奏。
- 弹簧、Combo、粒子、拖尾、浮字和震屏节奏。
- 启动、主页、HUD、暂停、结算与功能页的构图、比例、颜色和触控区域。
- 一屏平台数量、角色/云/收集物比例与可读性。
- 抖音开发者工具和真实竖屏手机的安全区、触控与性能。

## 仅在用户确认后处理

- 根据试玩反馈做小范围参数或布局修正。
- 接入用户提供且授权清晰的正式音频/美术资源。
- 在抖音开发者工具和真机完成最终平台验收。
- 用户明确批准后再决定是否合并 master。

## 继续保持不开发

- 旧 HTML 没有的玩法或 UI 重新设计。
- 正式抖音排行、广告、云存档、支付和商业化。
- 来源不明的第三方 SDK、音频或图片。
- 对历史备份、`Main.scene`、`HomeShell.scene` 或旧 HTML 原版的删除、覆盖和回写。

## 路线维护规则

- 旧 HTML 是迁移标准，用户试玩反馈是最终标准。
- 自动化只验证编译、导入、导航、按钮、存档和稳定性。
- 后续版本继续同步 README、变更说明、HANDOFF、ROADMAP 和迁移矩阵。
