# 《蹦蹦云》开发路线

更新时间：2026-07-23
当前完成版本：v2.9.4 HTML 高一致度复刻交互修正版

## v2.9.4 已完成

- 修复主页设置、游戏设置和其他全屏面板的触摸穿透与同次触摸回弹。
- 深色模式切换不再关闭设置或触发统计入口。
- 游戏设置关闭只恢复游戏。
- 六种技能恢复真实触发、消耗、持续、冷却、暂停恢复和不可用原因。
- 开始按钮防重复；Game 预加载与旧版节奏的短过渡并行。
- 不同云连续落点加入有上限的 Combo 节奏与反馈增强，异常中断时恢复基础速度。
- 完成 TypeScript、Creator 浏览器/抖音构建、竖屏浏览器流程、六技能和控制台检查。
- 保持 `agent/html-parity` 独立，未修改或合并 `master`。

## 当前停止线

可试玩版本完成后停止。自动化只证明编译、构建、流程和技能状态，不证明“好玩”。全部视觉与手感结论：**等待用户试玩确认。**

## 等待用户反馈

- 主页设置和游戏设置在真实手机上的遮挡与关闭行为。
- 开始过渡的速度、云雾节奏与 Game 淡入。
- 六种技能的手机触控、提示、实战效果和冷却可读性。
- 连续落云提速幅度、上限、重置时机及 Combo 反馈。
- 跳跃、水平控制、下降、镜头和弹簧的整体手感。

## 仅在用户确认后处理

- 根据试玩反馈做小范围参数或布局修正。
- 接入用户提供且授权清晰的正式音频或美术资源。
- 在抖音开发者工具和真机完成最终平台验收。
- 用户明确批准后再决定是否合并 `master`。

## 继续不做

- 旧 HTML 没有的玩法或 UI 重新设计。
- 正式抖音排行、广告、云存档、支付和商业化。
- 来源不明的 SDK、音频或图片。
- 对历史备份、`Main.scene`、`HomeShell.scene` 或旧 HTML 原版的覆盖与删除。
