代码侧 UI 优化完成。**等待用户试玩 v2.11.0 确认视觉与手感；上架动作依赖用户账号与授权。**

## 等待用户反馈

- 音效与 BGM 的音量、音色、场景适配（程序合成基础版）。
- 主页与游戏的手感、遮挡、过渡（延续 v2.9.4 待确认清单）。

## 用户侧上架路线

1. 微信：注册小游戏账号（个人主体、休闲类目）→ 提供 AppID → 替换构建配置 → 微信开发者工具验收 → MP 后台隐私声明与类目材料 → 上传审核（详见 docs/微信上架准备清单.md）。
2. 抖音：完成软著补正取得证书 → 抖音开发者工具导入 build/bytedance-mini-game 验收 → 真机回归 → 资质提交（详见现有抖音流程）。
3. 快手（暂缓）：需企业主体；条件齐备后按 docs/快手前置条件清单.md 启动。

## 后续版本候选（未承诺）

- 正式音频/美术素材接入（用户提供后替换）。
- 平台好友排行（微信开放数据域/抖音关系链）——需要时再做，涉及隐私声明。
- 广告/支付等商业化（需用户明确立项，个人主体在微信侧受 IAP 限制）。

## 继续不做

- 旧 HTML 没有的玩法或 UI 重新设计。
- 来源不明的 SDK、音频或图片。
- 对历史备份、`Main.scene`、`HomeShell.scene` 或旧 HTML 原版的覆盖与删除。
- 未经用户明确要求的发布、审核提交、支付、广告开通或账号绑定。
