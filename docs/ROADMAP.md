# 《蹦蹦云》开发路线

更新时间：2026-07-16
基线版本：v2.7.0

## 下一版本：v2.7.1 稳定验证版（待用户确认）

本版本只处理 v2.7.0 场景与手机显示基线的验证和明确缺陷，不主动增加玩法。

- 在 Cocos Creator 构建面板确认 Boot、Home、Game 均进入构建并以 Boot 启动。
- 在抖音开发者工具验证启动、场景切换、本地存储、onShow/onHide 和安全区。
- 至少一台真实竖屏手机验证标准 UI、大字模式、左右触摸及 HUD 遮挡。
- 实测开局和稳定上升阶段的一屏云数量；用户确认后再决定是否调整相机视野。
- 复测节点数量、收集物池、粒子池、FPS、Draw Call 和内存趋势。
- 只修复明确 Bug；普通跳跃、重力、水平参数、碰撞和云概率默认不动。
- 由用户决定是否保留或删除不参与正式流程的 `HomeShell.scene`。

## 后续候选：v2.8.0 内容补全版

需在 v2.7.1 验证完成后重新确认范围，候选内容：

- 音效、音乐及开关持久化。
- 本地排行榜页面和累计统计页面。
- 关卡目标、关卡完成、里程碑和完整浮动得分文字。
- 分步新手提示。
- 继续补齐 HTML 迁移矩阵中标为“部分完成”的项目。

## 暂不开发

- Combo 8 暴击冲刺、Combo 12 超级冲刺。
- 完整技能系统和键盘 1～6 技能操作。
- 正式抖音排行榜、广告、云存档、支付及商业化。
- 大量皮肤、关卡或新收集物。
- 未经用户确认的普通跳跃、重力、水平操作、碰撞和经济规则调整。
- 对历史备份、Main.scene 或旧 HTML 原版的删除、覆盖和回写。

## 路线维护规则

- 每完成一个版本或重要修改，同步更新本文件与 `HANDOFF.md`。
- 已完成内容从路线中移除，并在 HANDOFF 中记录真实验证结果。
- 新功能只进入“下一版本”后才允许实现；候选内容不等于已批准范围。
