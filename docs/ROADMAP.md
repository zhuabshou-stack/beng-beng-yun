# 《蹦蹦云》开发路线

更新时间：2026-07-19
当前完成版本：v2.9.2 HTML 高一致度迁移试玩版

## v2.9.2 已完成

- 从 v2.8.0 冻结提交建立 `agent/html-parity`，不改 master 和 `agent/v2.8.0`。
- 完整审计旧 HTML/CSS/JS；确认旧版没有独立图片或音频资源。
- 按旧版页面结构迁移首页、游戏、暂停、结算、关卡完成、皮肤、技能、排行、统计、设置和教学。
- 按 60 FPS 旧代码换算跳跃、重力、水平移动、云尺寸/间距、镜头、弹簧和 Combo。
- 迁移四种云、金币、星星、羽毛、六套皮肤、六种技能、关卡和本地数据。
- 迁移拖尾、落云/弹簧/收集粒子、浮字、Combo、震屏和里程碑。
- 删除 v2.8.0 精准落点、Combo 超时、8/12 冲刺等不属于旧版的正式分支。
- 完成 Creator/TypeScript、浏览器构建和抖音本地构建检查；提供页面截图。

## 当前停止线

可试玩迁移版完成后停止。所有主观结论统一为“等待用户试玩确认”，不合并 master，不自动开始下一版本。

## 等待用户反馈

- 跳跃高度、腾空时间和下落速度是否与旧 HTML 一致。
- 水平响应、松手阻尼和左右环绕是否一致。
- 镜头阈值与追随节奏是否一致。
- 弹簧倍率、Combo 提示、震屏和浮字节奏是否一致。
- 首页/HUD/暂停/结算/功能页构图、尺寸比例和颜色关系是否一致。
- 一屏平台数量、玩家/云比例以及金币、星星、羽毛的可读性。

## 仅在用户确认后处理

- 根据用户试玩反馈做小范围参数或布局修正。
- 接入用户提供且授权清晰的正式音频/美术资源。
- 在抖音开发者工具和真实竖屏手机完成安全区、触控、生命周期和性能验收。
- 用户明确批准后再决定是否合并 master。

## 继续保持不开发

- 旧 HTML 没有的玩法或 UI 重设计。
- 正式抖音排行榜、广告、云存档、支付和商业化。
- 来源不明的第三方 SDK、音频或图片。
- 对历史备份、`Main.scene`、`HomeShell.scene` 或旧 HTML 原版的删除、覆盖和回写。

## 路线维护规则

- 旧 HTML 是迁移标准，用户试玩反馈是最终标准。
- 自动化只证明编译、导航、按钮、存档和稳定性，不证明“好玩”。
- 任何后续版本继续同步 README、变更说明、HANDOFF、ROADMAP 和迁移矩阵。
