# 《蹦蹦云》开发路线

更新时间：2026-07-19
当前完成版本：v2.8.0

## v2.8.0 已完成

- 手感参数集中到 GameConfig：普通跳跃、水平移动、镜头、弹簧和 Combo 冲刺。
- 落云/精准/Combo/弹簧/收集反馈与固定对象池。
- 主页、HUD、暂停、结算整理；标准 UI 与大字模式。
- 本地排行榜、累计统计、完整设置页和统一音频架构。
- 首次分步教学、里程碑、基础旅程完成反馈。
- Creator/TypeScript、浏览器构建、600 秒连续游玩、内存趋势和抖音包本地构建检查。

## 当前停止线

v2.8.0 交付后停止，不自动开始新版本。下一版本范围由用户重新确认。

## 后续候选（未批准）

- 根据用户手机试玩结果微调跳跃、水平惯性、镜头、弹簧与冲刺参数。
- 接入用户提供且授权清晰的正式音效、音乐和美术资源。
- 在至少一台真实竖屏手机完成安全区、触控、生命周期和性能验收。
- 继续完善皮肤视觉展示，但不得在未确认前建立完整经济或商业化系统。

## 继续保持不开发

- 完整技能系统和键盘 1～6 技能操作。
- 正式抖音排行榜、分享、广告、云存档、支付和商业化。
- 羽毛系统、完整皮肤经济、大量关卡或新收集物。
- 未经用户确认的碰撞体、四种云概率/规则、基础收集逻辑或存档语义变更。
- 对历史备份、Main.scene、HomeShell.scene 或旧 HTML 原版的删除、覆盖和回写。

## 路线维护规则

- 每完成一个版本同步更新本文件、HANDOFF、README、变更说明和 HTML 迁移矩阵。
- 主观手感必须由用户试玩确认；自动回归只能证明输入、状态和稳定性链路。
- 抖音平台规则、API、审核或发布工作必须先查询当时官方文档并单独获得授权。
