## 二、工程侧（已完成 / 待办）

- ✅ Cocos 3.8 内置微信小游戏构建目标，构建产物 `build/wechatgame`（含 game.json、project.config.json）。
- ✅ 平台能力已收敛到 `PlatformService`（分享/震动/前后台/安全区），微信运行时走 `WechatBridge`。
- ✅ 非调试模式构建包体约 3.6MB（低于 4MB 主包限额）。
- ⬜ 构建配置暂用官方测试 AppID `wx6ac3f5090a6b99c5`，拿到正式 AppID 后替换 `profiles/v2/packages/wechatgame.json` 重新出包。
- ⬜ 引擎插件（可选优化）：微信引擎插件仅在**非调试模式**生效；命令行传参可能不写入平台选项，正式出包建议在编辑器构建面板勾选「分离引擎」后构建。首次在微信开发者工具打开若提示"插件未授权使用"，点提示中的「添加插件」选择 CocosCreator 插件后重新编译。
- ✅ 代码零隐私 API：不调用 `wx.getUserInfo`、`createUserInfoButton`、`getFriendCloudStorage`、剪贴板等。

## 三、微信开发者工具验证步骤

1. 安装「微信开发者工具」（stable 版），用注册微信扫码登录。
2. 工具「设置 → 安全设置」开启服务端口（Cocos 构建任务点"运行"可自动拉起）。
3. 导入目录：`build/wechatgame`，AppID 填测试号或正式号。
4. 预览：真机扫码（先在工具内点「预览」生成二维码）。
5. 上传：工具右上角「上传」→ 填版本号与备注 → MP 后台「版本管理」提交审核。

## 四、隐私与内容合规

1. MP 后台「设置 → 服务内容声明 → 用户隐私保护指引」：即使不处理任何个人信息，也需确认承诺"未处理用户任何信息"。
2. 本游戏当前不触发隐私弹窗（无隐私接口调用）；若日后加好友排行（开放数据域），必须声明「微信朋友关系」并接隐私弹窗。
3. 排行榜为纯本地成绩，不涉及好友关系链，无合规风险。
4. 审核质量注意：音效属于官方点名的质量要素，v2.10.0 已补基础音效与 BGM；避免空壳观感。

## 五、审核提交前自查

- [ ] 加载无黑屏卡死，首屏时间可接受。
- [ ] 游戏简介、截图（MP 后台配置）与实际内容一致。
