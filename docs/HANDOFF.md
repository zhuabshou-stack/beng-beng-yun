## 当前场景架构

- `assets/Boot.scene`：启动 Logo、云雾星光、约 1.5 秒加载动画，预加载 Home。
- `assets/Home.scene`：独立主页；不创建 World、Player 或 GameManager。
- `assets/Game.scene`：游戏世界、HUD、暂停、结算、重开与返回主页。
- `assets/Main.scene`：旧可运行基线，保留不改。
- `assets/HomeShell.scene`：Creator 创建过程的备用壳，不在正式流程中；删除前需用户确认。
- 正式启动流程：`Boot → Home → Game → Home`。
- `profiles/v2/packages/preview.json` 的启动场景 UUID 指向 Boot。
