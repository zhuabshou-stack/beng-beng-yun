# 《蹦蹦云》私人 GitHub 同步规则

- 指定私人仓库名称：`beng-beng-yun-private`。
- 仅同步经过测试和敏感信息检查的正式源代码及项目必需文档。
- 不同步 Cocos 缓存、构建产物、依赖目录、日志、版本备份、环境变量、平台凭证或本机私有配置。
- 每个正式版本完成且测试通过后，更新 README、变更说明与 `docs/HANDOFF.md`，再创建对应版本提交并推送。
- 仓库必须始终保持 Private，不得改为 Public，也不得添加其他协作者。
- 每次提交和推送前必须复核 `.gitignore`，并对全部待提交文件执行敏感信息扫描。
- 发现敏感信息、认证异常、远程地址变化、仓库并非 Private、测试失败、合并冲突或用户停止信号时，必须停止提交或推送。
